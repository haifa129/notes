
## Week 1
- Early writing systems were used to record information before computers existed.
- Printing made it easier to produce and share written information.
- Fonts determine how letters and characters appear.

## Week 2
- RAM is temporary memory that loses its data when the computer turns off.
- Persistent storage keeps files even when the computer is turned off.
- ASCII represents characters using numbers.
- Computers store information using binary digits (0 and 1).

## Week 3
- Markdown and HTML are markup languages used to format and organize text.
- Whitespace includes spaces, tabs, and line breaks.
- JSON and XML are formats used to organize and exchange structured data.
- Escaping allows special characters to be treated as regular text.

## Week 4
- Touch typing allows people to type without looking at the keyboard.
- Keyboard shortcuts help users perform tasks faster.
- VS Code, Notepad, and Vim are examples of text editors.
- Regular expressions help search for specific text patterns.

## Week 5
- A Command Line Interface (CLI) allows users to interact with a computer by typing commands.
- A terminal provides an interface for accessing a command-line shell.
- SSH allows secure remote access to another computer.
- SFTP and SCP are used to transfer files securely.
